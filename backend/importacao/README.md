# Importação de agências

Coloque aqui a planilha do **Infotravel** exportada como **CSV** (de preferência
**CSV UTF-8**), por exemplo: `agencias_infotravel.csv`.

Esta pasta é só fonte de dados de importação. Os arquivos `.csv`/`.xlsx` aqui
são **ignorados pelo Git** — dados da operação não vão pro repositório.
